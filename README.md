# Система управления оценками и задачами студента

Консольное приложение на Java. Позволяет студенту записывать учебные задачи с оценками, смотреть их список и считать средний балл. Весь код находится в одном файле `Main.java`.

## Возможности

Меню программы:

| Пункт | Что делает |
|-------|------------|
| 1 | Добавить задачу (название, предмет, оценка) |
| 2 | Посмотреть список всех задач |
| 3 | Посчитать средний балл |
| 4 | Выход |

Оценки ставятся по 5-балльной шкале (1–5). Если оценки ещё нет, вводится `0`: такая задача сохраняется, но в средний балл не входит.

## Технологии

- **Java 17 или новее** (используется запись `case ... ->` в `switch`)
- **Scanner** из стандартной библиотеки для ввода с клавиатуры
- **ArrayList / List** для хранения задач
- Никаких внешних библиотек и сборщиков (Maven, Gradle) не нужно

## Как запустить

1. Установите JDK 17 или новее. Проверить можно командой `java -version`.
2. Откройте терминал в папке, где лежит `Main.java`.
3. Скомпилируйте программу:

   ```bash
   javac Main.java
   ```

4. Запустите её:

   ```bash
   java Main
   ```

Если в Windows вместо русских букв отображаются знаки вопроса, выполните перед запуском `chcp 65001`.

## Объяснение кода для новичка

В файле три класса. Представьте их так: **`Task`** — это одна карточка с задачей, **`Student`** — папка, в которой лежат карточки, а **`Main`** — «пульт управления», через который пользователь общается с программой.

### Класс `Task` (задача)

```java
class Task {
    private final String title;
    private final String subject;
    private final int grade;
    ...
}
```

Хранит три значения: название, предмет и оценку. Слово `private` значит, что снаружи к ним нельзя обратиться напрямую. Слово `final` значит, что после создания задачи значение уже не изменится.

- **Конструктор** `Task(String title, String subject, int grade)` создаёт новую задачу и запоминает переданные данные.
- **`isGraded()`** отвечает на вопрос «есть ли оценка?». Если оценка больше нуля, ответ `true`.
- **`toString()`** описывает, как задача выглядит в виде текста. Именно он работает, когда мы печатаем задачу через `System.out.println(...)`.

### Класс `Student` (студент)

```java
class Student {
    private final String name;
    private final List<Task> tasks = new ArrayList<>();
    ...
}
```

Хранит имя студента и список его задач. `ArrayList` — это «резиновый» список: в него можно добавлять элементы, и он сам расширяется.

- **`addTask(Task task)`** кладёт новую задачу в список.
- **`getTasks()`** отдаёт список задач, чтобы его можно было показать.
- **`calculateAverage()`** считает средний балл:
  1. Идёт по всем задачам в цикле `for`.
  2. Если у задачи есть оценка, прибавляет её к сумме и увеличивает счётчик.
  3. В конце делит сумму на количество оценённых задач.
  4. Если оценённых задач нет, возвращает `-1`. Это сигнал «посчитать нельзя», потому что делить на ноль нельзя.

### Класс `Main` (программа)

Здесь всё, что связано с общением с пользователем.

**Точка входа — `main`.** Java начинает выполнение программы именно с метода `main`. Он делает так:

1. Спрашивает имя и создаёт объект `Student`.
2. Запускает цикл `while (running)`. Пока переменная `running` равна `true`, меню показывается снова и снова.
3. Читает выбор пользователя и через `switch` вызывает нужное действие: добавить задачу, показать список или посчитать средний балл.
4. При выборе пункта 4 ставит `running = false`, цикл заканчивается, и программа завершается.

**Чтение ввода — `Scanner`.** Объект `scanner` умеет читать то, что пользователь печатает в консоли. Метод `nextLine()` читает целую строку. Он создан один раз и используется во всей программе.

**Два вспомогательных метода защищают от ошибок ввода:**

- **`readNonEmptyLine()`** не принимает пустую строку. Если пользователь просто нажал Enter, программа попросит ввести значение снова.
- **`readInt(prompt, min, max)`** читает целое число в заданных границах. Если введено не число (`Integer.parseInt` выбрасывает ошибку `NumberFormatException`) или число вне диапазона, программа сообщает об этом и спрашивает заново. Ошибку ловит блок `try ... catch`, поэтому программа не падает.

**Методы-действия** по одному на каждый пункт меню:

- `addTask` спрашивает у пользователя название, предмет и оценку, создаёт `Task` и добавляет его студенту.
- `showTasks` печатает пронумерованный список задач или сообщение, что список пуст.
- `showAverage` печатает средний балл с двумя знаками после запятой (`%.2f`) или сообщение, что оценённых задач нет.

### Как всё связано

```
Пользователь вводит данные
        ↓
   Main читает их через Scanner
        ↓
   создаёт Task и кладёт в Student
        ↓
   Student хранит список и считает среднее
        ↓
   Main выводит результат на экран
```

## Идеи для развития

- Сохранять задачи в файл, чтобы они не пропадали после выхода.
- Добавить удаление и редактирование задач.
- Считать средний балл отдельно по каждому предмету.
